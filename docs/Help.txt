WORKSTATION MIGRATION TOOLKIT v3.0.0-m1 — ՕԳՆՈՒԹՅՈՒՆ
=====================================================

ՈՒՇԱԴՐՈՒԹՅՈՒՆ. Սա M1 փուլն է (Discovery/UI shell)։ Ծրագիրը ՄԻԱՅՆ գույքագրում է
տեղադրված ծրագրերն ու Windows-ի օգտատիրական պրոֆիլները։ Backup, Verify և Restore
դեռ չկան (M3–M4)։ Այսինքն՝ այս տարբերակով ձեր տվյալները ՉԵՆ պահուստավորվում։
Windows 10-ը մի՛ ջնջեք՝ մինչև անկախ պահուստի և Restore-ի հաստատումը։

ՈՐՏԵՂ Է ԳՈՐԾՈՒՄ
- Ծրագիրը ոչինչ չի փոփոխում, չի ջնջում և չի պատճենում։ Միայն կարդում է Registry-ի
  Uninstall բաժինները և պրոֆիլների ցանկը։
- Բացվելիս ցուցակները դատարկ են («Not scanned»)։ Սկանավորումը ՉԻ սկսվում ինքնաբերաբար։
- Սկանավորման ընթացքում կոճակներն ու ընտրությունները անջատվում են, ավարտից հետո
  (հաջողություն, սխալ կամ Cancel) վերադառնում են։

ՀԵՐԹԱԿԱՆՈՒԹՅՈՒՆ
1. Software ներդիր → «Discover software»։
2. User profiles ներդիր → «Discover profiles»։
3. Ընտրեք ձեզ անհրաժեշտ տողերը («Use» սյունակ)։ Ընտրությունը M1-ում դեռ ոչ մի բանի
   համար չի օգտագործվում․ այն կպահպանվի և կօգտագործվի M2-ում (Migration plan)։

ՆԵՐԴԻՐՆԵՐ
Software
  Տեղադրված ծրագրերի ցանկ (Registry 32/64-bit + ընթացիկ օգտատիրոջ գրառումներ)։
User profiles
  Windows-ի իրական օգտատերերը (համակարգային և ծառայությունների պրոֆիլները թաքցված են)։

ԿՈՃԱԿՆԵՐ
Discover software
  Կարդում է տեղադրված ծրագրերի ցանկը։ Աշխատում է ֆոնում, ինտերֆեյսը չի սառչում։
  Նոր սկանից հետո նախկին ընտրությունը պահպանվում է (անուն+տարբերակ+ճարտարապետություն)։
Search
  Որոնման դաշտ՝ զտում է ըստ անվան, հրատարակչի, տարբերակի, տեսակի։ Թաքցված տողերի
  ընտրությունը չի կորչում։
Select all
  Ընտրում է ՄԻԱՅՆ ներկայումս երևացող (զտված) տողերը։
Clear
  Հանում է ընտրությունը երևացող տողերից։
Invert
  Շրջում է ընտրությունը երևացող տողերի համար։
Office details
  Ցույց է տալիս Office-ի տարբերակը, build-ը, x86/x64, տեղադրման ձևը և proofing
  բաղադրիչները։ Համեմատման կանոններ՝ ճարտարապետության անհամապատասխանությունը
  արգելափակում է ռիսկային քայլերը, այլ ընտանիքը զգուշացում է, միայն build-ի
  տարբերությունը ինքնին անհամատեղելիություն չէ։ Word add-in-երը M1-ում չեն ստուգվում։
Discover profiles
  Կարդում է Windows-ի օգտատիրական պրոֆիլները (SID, ուղի, բեռնված է թե ոչ, հասանելի է թե ոչ)։
  Հին SID-ը նոր SID-ին ավտոմատ չի համապատասխանեցվում։
Cancel
  Կանգնեցնում է ընթացիկ գործողությունը (ստատուս բարի աջ կողմում)։

ՄԵՆՅՈՒ
Help
  Այս օգնությունը։
Open log
  Բացում է աշխատանքային լոգը Notepad-ում։ Ֆայլ՝ %LOCALAPPDATA%\WMT\Logs\wmt-ՏՏՏՏԱԱՕՕ.log
About
  Տարբերակ և լոգի ուղի։

ՍՅՈՒՆԱԿՆԵՐ — Software
Use       ընտրման նշան
Name      ծրագրի անունը
Publisher հրատարակիչ (կարող է դատարկ լինել)
Version   տարբերակ (դատարկ՝ եթե Registry-ում չկա)
Architecture  x64 / x86 ՝ ըստ Registry-ի տեսքի (HKCU-ի համար՝ Unknown)
Source    որ Registry բաժնից է գտնվել
Type      Application / Runtime / Office / Python
Recovery method  ինչպես վերականգնել (օր.՝ Runtime-ի դեպքում՝ reinstall manifest, DLL-ների պատճենում չկա)
Status    վստահություն՝ Confirmed (անուն+տարբերակ կա) կամ Inferred (տարբերակ չկա)

ՍՅՈՒՆԱԿՆԵՐ — User profiles
Use, Account, SID, Profile path, Loaded (ներկայումս բեռնված է Registry-ում),
Accessible (Accessible / Unreadable / Missing), Last used (NTUSER.DAT-ի վերջին փոփոխություն,
կամ unknown), Note (օր.՝ պետք է administrator իրավունք)։
Office  (ներքևի շրջանակ Software ներդիրում) — Office details-ի արդյունքը։

ՍՏԱՏՈՒՍ ԲԱՐ (ներքևում)
Փուլի անուն, ֆայլաքանակ/տարրաքանակ, առաջընթաց (հայտնի ընդհանուրի դեպքում՝ տոկոսով,
անհայտի դեպքում՝ indeterminate), վերջին ակտիվության ժամը։ Եթե 60 վայրկյան նոր
առաջընթաց չկա, երևում է «No recent progress — investigate» (դա ՉԻ նշանակում, թե
ծրագիրը կախվել է)։ Բաժանարար գծերը (ցուցակի և լոգի միջև) քաշվում են մկնիկով։

ԱՌԱՆՁԻՆ ԳՈՐԾԱՐԿԻՉ ԱԽՏՈՐՈՇՄԱՆ ՀԱՄԱՐ
Launch-WMT-Diagnostics.cmd — բացում է ծրագիրը և միաժամանակ լոգը։

ՍԱՀՄԱՆԱՓԱԿՈՒՄՆԵՐ (M1)
- Portable ծրագրեր և winget ցանկ դեռ չկան։ Ծրագիր, որ Registry-ում Uninstall գրառում
  չունի, չի երևա։ «Չերևալը» ՉԻ նշանակում, թե ծրագիրը չկա։
- Office-ի Word add-in-երի, VBA-ի, ձևանմուշների և Python/OCR միջավայրերի հայտնաբերումը՝ M2։
- Registry-ի 32/64-bit տեսքերը ճիշտ են կարդացվում, բայց «Architecture»-ը Registry-ի
  տեսքից է եզրակացվում և ոչ թե գործարկվող ֆայլից։
- Լոգը պահվում է %LOCALAPPDATA%\WMT\Logs, ոչ թե backup destination-ում (Backup դեռ չկա)։
