WORKSTATION MIGRATION TOOLKIT 4.0 — ՕԳՆՈՒԹՅՈՒՆ (Help)
=========================================================

ԻՆՉ Է ԱՆՈՒՄ ԾՐԱԳԻՐԸ
Ծրագիրը օգնում է Windows 10-ից Windows 11-ի մաքուր տեղադրման ժամանակ պահպանել և վերականգնել
ձեր աշխատանքային միջավայրը՝ ընտրված ծրագրերի անհատական կարգավորումները (Word-ի ձևանմուշներ,
մակրոսներ, բառարաններ, հավելումներ), Python/OCR նախագծերը և մոդելները, օգտատիրական պանակները,
ինչպես նաև վերատեղադրման համար անհրաժեշտ ամբողջ տեղեկությունը։

ՀԻՄՆԱԿԱՆ ԿԱՆՈՆՆԵՐ
• Ծրագիրը ինքնաբերաբար ոչինչ չի սկանավորում. ամեն քայլ սկսվում է ձեր սեղմումով։
• Սկանավորումը, Backup-ը և Verify-ը աղբյուր ֆայլերը միայն կարդում են. ոչինչ չեն փոխում և չեն ջնջում։
• Ծրագրերի տեղադրման ֆայլերը, Windows/Office-ի DLL-ները, cache-երը, Python-ի .venv/site-packages-ը
  լռելյայն ՉԵՆ պատճենվում. դրանց փոխարեն պահվում է վերատեղադրման տեղեկությունը։
• Պատճենված ֆայլերը պահվում են իրենց իրական անուններով և պանակներով. դրանք կարելի է բացել
  Windows Explorer-ով նույնիսկ առանց այս ծրագրի։
• Գաղտնաբառեր, token-ներ, լիցենզիոն բանալիներ և Office-ի ակտիվացում չեն արտահանվում։
• «Copied» ≠ «Verified» ≠ «Restored» ≠ «FunctionallyValidated». սրանք տարբեր վիճակներ են։
• Նույն ֆիզիկական սկավառակի այլ բաժինը (օրինակ՝ G:) անկախ պահուստ ՉԷ։ Windows 10-ը ջնջելուց առաջ
  պատճենեք փաթեթը այլ սարքի վրա (արտաքին սկավառակ, այլ համակարգիչ)։

ԱՇԽԱՏԱՆՔԻ ՀԵՐԹԱԿԱՆՈՒԹՅՈՒՆԸ
 1. Software ներդիր → Discover software → ընտրեք ձեզ անհրաժեշտ ծրագրերը (օր.՝ Microsoft Office, Python, Tesseract)։
 2. User Profiles ներդիր → Discover profiles → ընտրեք պրոֆիլ(ներ)ը, ըստ ցանկության՝ օգտատիրական պանակներ
    և Custom folders (any drive)։
 3. Keyboard Layouts ներդիր → Discover keyboard layouts (ձեր Keyboard Layout Creator-ով ստեղծած դասավորությունները)։
 4. Windows Settings ներդիր → Discover Windows settings → ընտրեք պահվող կարգավորումները։
 5. Migration Plan ներդիր → Generate targeted plan → դիտեք և ճշգրտեք ընտրությունը։
 6. Backup & Recovery → 1. Backup → ընտրեք արդեն գոյություն ունեցող նպատակային պանակ → Preview / Dry run →
    Create backup։
 7. 2. Verify and Test Restore → Verify backup → Test restore (sandbox)։
 8. 3. Readiness → հետևեք, որ բոլոր տողերը դառնան Ready։ Միայն դրանից հետո կարելի է ջնջել Windows 10-ը։
 9. Նոր Windows 11-ում՝ տեղադրեք ծրագրերը, բացեք այս ծրագիրը, Open package → Keyboard Layouts (Install selected
    layouts, ապա Restore language list and keyboard order) → 4. Restore (ֆայլեր) → Windows Settings (Apply selected settings)։

ՆԵՐԴԻՐ Software
========================================
Discover software — կարդում է տեղադրված ծրագրերի ցանկը Windows Registry-ից (64-bit, 32-bit, ընթացիկ
  օգտատիրոջ և մյուս մուտք գործած օգտատերերի գրառումներ) և հայտնի portable պանակներից։ Աշխատում է ֆոնում։
  Նոր սկանից հետո նախկին ընտրությունը պահպանվում է։ Ցանկում բացակայելը չի նշանակում, որ ծրագիրը չկա։
Also query winget — լրացուցիչ աղբյուր. winget-ի ցանկը պահվում է փաթեթում (winget import-ի համար)։ Միակ աղբյուր չէ։
Search — որոնում ըստ անվան, հրատարակչի, տարբերակի կամ տեղադրման ուղու։
Filter — ցույց է տալիս միայն ընտրված տեսակը (Application, Office, Python, OCR, Runtime, Development, Portable)։
Group by — խմբավորում ըստ Publisher, Category կամ Recovery method։
Select all — ընտրում է ՄԻԱՅՆ ներկայումս երևացող տողերը։
Clear — հանում է ընտրությունը երևացող տողերից։
Invert — շրջում է երևացող տողերի ընտրությունը։
Export list — պահում է ցանկը CSV և JSON ձևաչափերով։
Սյունակներ.
  Selected — ընտրված է միգրացիայի համար։   Name — անուն։   Publisher — հրատարակիչ (Unknown, եթե հայտնի չէ)։
  Version — տարբերակ։   Build — build (Unknown, եթե հուսալիորեն հայտնի չէ)։   Architecture — x64/x86/Unknown։
  Installation Type — MSI, Installer (EXE), Per-user, Click-to-Run, Portable։
  Install Location — տեղադրման պանակ։   Detected Source — որտեղից է գտնվել։   Type — ծրագրի տեսակը։
  Recovery Method — ինչպես վերականգնել (օր.՝ runtime-ը վերատեղադրվում է, DLL-ները չեն պատճենվում)։
  Dependency Status — կախվածությունների ամփոփում (հաշվարկվում է պլանից հետո)։
Office details — ներքևի շրջանակ։ Show Office details կոճակը ցույց է տալիս Office-ի product/edition, release,
  տարբերակ, build, x86/x64, տեղադրման ձև և լեզվային/proofing բաղադրիչներ։ Համեմատման կանոններ՝
  ճարտարապետության անհամապատասխանությունը արգելափակում է ռիսկային քայլերը, այլ release-ը զգուշացում է,
  նույն release-ի այլ build-ը ինքնին անհամատեղելիություն չէ։

ՆԵՐԴԻՐ User Profiles
========================================
Discover profiles — ցույց է տալիս Windows-ի իրական օգտատերերին (համակարգային պրոֆիլները թաքցված են)։
  Ոչ մի պրոֆիլ ինքնաբերաբար չի ընտրվում։
Select all / Clear / Invert — խմբային ընտրություն։   Select current user — ընտրում է միայն ձեզ։
Սյունակներ. Selected, Account (հաշիվ), SID, Profile path (պրոֆիլի պանակ), Loaded (registry-ն բեռնված է),
  Accessible (Accessible / Inaccessible / Missing), Last used (NTUSER.DAT-ի վերջին փոփոխություն կամ unknown),
  Note (օր.՝ պետք է administrator իրավունք)։ Ծրագիրը երբեք չի շրջանցում թույլտվությունները։
User data folders of the selected profiles (opt-in; scanned only when you generate the plan) —
  Desktop, Documents, Downloads, Pictures, Videos, Music, Favorites։ Լռելյայն ոչ մեկը նշված չէ։
  Մեծ պանակները սկանավորվում են միայն պլան ստեղծելիս։
Custom folders (any drive) — ձեր սեփական պանակները ցանկացած սկավառակից։ Add folder — ավելացնել,
  Remove folder — հեռացնել։ Իրար մեջ ներդրված պանակները ավտոմատ միավորվում են, կրկնապատճենում չկա։
Options —
  Runtimes (reinstall list) — Visual C++/.NET/և այլն՝ որպես վերատեղադրման ցուցակ (ոչ թե DLL-ների պատճեն)։
  Empty folders — դատարկ պանակների ռեժիմ. լռելյայն բացառվում են, կարելի է պահել ծրագրային կարգավորումների
    ներսում կամ բոլորը։ Անհասանելի պանակը երբեք «դատարկ» չի համարվում։

========================================
ՆԵՐԴԻՐ Keyboard Layouts (ստեղնաշարի դասավորություններ)
========================================
Microsoft Keyboard Layout Creator (MSKLC) գործիքով ստեղծված դասավորությունը Windows-ում բաղկացած է մեկ DLL ֆայլից
(System32 և SysWOW64 պանակներում) և դրա գրանցումից ռեեստրում (KLID)։ Ծրագիրը պահում է վերատեղադրելու բոլոր աղբյուրները.
  1) սկզբնական setup փաթեթը (setup.exe + *_amd64.msi), եթե գտնվի ձեր պանակներում,
  2) Windows-ի Installer cache-ում պահված նույն MSI-ն (նույնիսկ եթե սկզբնականը կորել է),
  3) տեղադրված DLL ֆայլերը — նոր Windows-ում ծրագիրը ԻՆՔՆ է դրանք տեղադրում ու գրանցում (MSKLC պետք չէ),
  4) .klc աղբյուր ֆայլը — ձերը, եթե գտնվի, և ծրագրի ԻՆՔՆԱՇԽԱՏ ստեղծածը տեղադրված DLL-ից (նույնը, ինչ MSKLC-ում
     File → Load Existing Keyboard → Save As)։ .klc-ով դասավորությունը կարելի է բացել ու խմբագրել MSKLC-ում։
Discover keyboard layouts — գտնում է դասավորությունները, ձեր լեզուների ցանկն ու դասավորությունների հերթականությունը,
  և յուրաքանչյուր ձեր դասավորության համար ստեղծում .klc ֆայլ։
  .klc և setup փաթեթները որոնվում են ընտրված պրոֆիլների Documents, Desktop, Downloads և Custom folders պանակներում։
Select custom layouts — ընտրում է ձեր ստեղծած (ոչ Windows-ի) բոլոր դասավորությունները։   Clear — հանում է ընտրությունը։
Save .klc files — ընտրված դասավորությունների .klc ֆայլերը պահում է Documents\WMT Keyboard Layouts պանակում և բացում այն։
  (Backup-ի ժամանակ դրանք ավտոմատ պահվում են նաև փաթեթի Reports\Keyboard պանակում։)
Open in MSKLC — առաջին ընտրված դասավորության .klc-ն բացում է Microsoft Keyboard Layout Creator-ում։ Եթե MSKLC-ն
  տեղադրված չէ, առաջարկում է բացել Microsoft-ի պաշտոնական ներբեռնման էջը (անվճար է)։
  Ներքևի մոխրագույն տողը ցույց է տալիս՝ գտնվե՞լ է արդյոք MSKLC-ն այս համակարգչում։
Սյունակներ. Selected, Layout (անուն), KLID (Windows-ի նույնացուցիչ, օր.՝ A000042B), Language, Custom
  (Yes — ձերն է, No (Windows) — Windows-ինն է), In your list (միացված է ձեզ մոտ), Best backup source (ինչով է
  վերականգնվելու), .klc generated (ստեղծվե՞լ է .klc ֆայլը), Layout file (DLL), Why custom (ինչու է համարվել ձերը)։
Restore from package (նոր Windows-ում, փաթեթը բացելուց հետո Backup & Recovery-ում).
  Install selected layouts — յուրաքանչյուր դասավորության համար ընտրում է լավագույն տարբերակը.
    ա) փաթեթում MSI կա → գործարկում է այն,
    բ) DLL կա → պատճենում է այն System32 / SysWOW64 և գրանցում KLID-ը (ճիշտ այնպես, ինչպես MSKLC-ի setup-ն է անում),
    գ) միայն .klc կա և MSKLC-ն տեղադրված է → MSKLC-ի կոմպիլյատորով (kbdutool) կառուցում է DLL-ը, ապա տեղադրում։
    Windows-ը կխնդրի administrator-ի թույլտվություն։ Արդեն տեղադրվածը չի կրկնվում, տարբեր պարունակությամբ նույնանուն
    ֆայլը կամ գրանցումը երբեք չի վերագրվում։ Տեղադրելուց հետո գուցե պետք լինի դուրս գալ ու նորից մուտք գործել (sign out)։
  Restore language list and keyboard order — վերականգնում է լեզուների ցանկն ու դասավորությունների հերթականությունը։

  Սյունակներ՝ Install, Layout, KLID, What will happen։

ՆԵՐԴԻՐ Migration Plan
========================================
Generate targeted plan — ընտրված ծրագրերի և պրոֆիլների համար սկանավորում է ՄԻԱՅՆ հայտնի կամ

========================================
ՆԵՐԴԻՐ Backup & Recovery
========================================
--- 1. Backup ---
Destination — արդեն գոյություն ունեցող պանակ (օր.՝ G:\Backup)։ Browse destination — ընտրել։
  Ծրագիրը ստեղծում է միայն մեկ ենթապանակ՝ Migration-<համակարգիչ>-<UTC ժամ>-<id> և ամեն ինչ դնում է դրա մեջ։
  Ծնող պանակները չեն ստեղծվում և չեն փոխվում։ Պանակը չի կարող լինել աղբյուր պանակների ներսում։
Preview / Dry run — ցույց է տալիս ֆայլերի քանակը, ծավալը, կատեգորիաները (Category, Files, Size, Classes,
  Destination rule), նախազգուշացումները և ֆիզիկական սկավառակի ստուգումը։ Ոչինչ չի գրում։
Create backup — պատճենում է ժամանակավոր .partial ֆայլի մեջ, համեմատում SHA-256-ը, հետո միայն վերջնականացնում։
  Սխալի դեպքում՝ սահմանափակ կրկնափորձ։ Չպատճենված ֆայլի դեպքում փաթեթը Incomplete է։
Retry failed files — կրկին փորձում է ՄԻԱՅՆ ձախողված ֆայլերը. հաջող պատճենները չեն վերագրվում։

--- 2. Verify and Test Restore ---
Open package — բացել առկա փաթեթ (օրինակ՝ նոր Windows-ում)։
Verify backup — միայն կարդալու ստուգում. վերահաշվում է բոլոր ֆայլերի SHA-256-ը և չափը, ստուգում է
  մանիֆեստները, բացակայող, ավելորդ, կրկնվող և վտանգավոր (..) ուղիները։ Ոչինչ չի ուղղում և չի վերագրում։
  SHA-256-ը ամբողջականության ստուգիչ է, ոչ թե թվային ստորագրություն։
Browse test folder — ընտրել ԴԱՏԱՐԿ փորձնական պանակ։
Test restore (sandbox) — վերականգնում է ֆայլերը միայն փորձնական պանակում և ստուգում բայթ առ բայթ։
  Իրական Windows/Office պանակներին չի դիպչում։
Open recovery plan — վերականգնման հերթականացված պլան (HTML)։   Open Python plan — PYTHON-RECOVERY-PLAN.txt։
Open backup report — հաջողված/ձախողված/բաց թողնված/ձեռքով քայլերի հաշվետվություն։
Open package folder — բացում է փաթեթի պանակը Explorer-ով։

--- 3. Readiness ---
Refresh readiness — թարմացնում է պատրաստվածության գնահատումը։
Export readiness report — պահում է հաշվետվությունը փաթեթի Status պանակում և բացում այն։
Սյունակներ՝ State (Ready / NeedsReview / Blocked / NotTested), Area, Item, Reason, Action, Confirmed։
  «Migration Ready» երևում է միայն, երբ բոլոր տողերը Ready են։ Արգելափակում են՝ չստուգված պահուստը,
  ձախողված կամ չկատարված Test restore-ը, ձախողված Python կախվածությունները, բացակայող installer-ը,
  Office հավելման անհամատեղելիությունը և անկախ պահուստի բացակայությունը։
  Confirmed վանդակը թույլատրված է միայն այն տողերի համար, որոնք կարող եք հաստատել դուք
  (օր.՝ «ունեմ Office-ի տեղադրման միջոցը», «պատճենել եմ փաթեթը այլ սարքի վրա»)։

--- 4. Restore --- (կատարվում է նոր Windows-ում)
Էջի վերևի կապույտ տողը ցույց է տալիս ամբողջ հերթականությունը նոր Windows-ում.
  A. տեղադրեք ձեր ծրագրերը (Office, Python…) → B. Keyboard layouts → C. Windows settings → D. ֆայլեր (այս էջի
  1–4 քայլերը) → E. Python environments։ B. Keyboard layouts և C. Windows settings կոճակները բացում են համապատասխան ներդիրը։
Կապույտ թավ տողը («Next — …») միշտ գրում է, թե ՀԻՄԱ ինչ անել։ Հետևեք դրան։
Step 1. Source account / Source profile path / Files — հին պրոֆիլները։ Target profile on this computer — ընտրեք,
  թե որ նոր պրոֆիլին է համապատասխանում հինը (սովորաբար ձերը՝ C:\Users\ՁերԱնունը)։ Ավտոմատ չի լրացվում։
Step 2. Dry run — ցույց է տալիս, թե ինչ կվերականգնվի (Files (dry run) և Registry (review) ցուցակներ)։ Ոչինչ չի փոխում։
  Եթե պրոֆիլը փոխեք, Dry run-ը սեղմեք նորից։
Step 3. Դիտեք ցուցակները. հանեք այն, ինչ պետք չէ։
  Select all / Clear — ցուցակի բոլոր վանդակները նշում / հանում է (յուրաքանչյուր ցուցակում իր կոճակները կան)։
  Վանդակը փոխվում է մեկ սեղմումով։ Մոխրագույն (անջատված) վանդակները չեն կարող նշվել (օր.՝ ֆայլն արդեն նույնն է)։
  Աջ սեղմում տողի վրա (մկնիկի տակի տողը) — մենյու.
    Restore only this item — վերականգնում է ՄԻԱՅՆ այդ տողը՝ անկախ մյուս վանդակներից։ Եթե այնտեղ արդեն կա
      տարբեր ֆայլ, հարցնում է՝ փոխարինե՞լ (հին ֆայլը պահվում է Undo-ի համար)։
    Tick highlighted rows / Untick highlighted rows — նշում/հանում է ընդգծված տողերը (Ctrl կամ Shift-ով կարող եք
      ընդգծել մի քանի տող, ապա աջ սեղմել. այդ դեպքում մենյուն կգրի «… only these N items»)։
    Select all / Clear all — նույնն է, ինչ վերևի կոճակները։
  Նույն մենյուն կա Registry (review) ցուցակում (Apply only this item), Windows Settings ներդիրի վերականգնման
  ցուցակում (Apply only this item) և Keyboard Layouts ներդիրի վերականգնման ցուցակում (Install only this item)։
Step 4. Restore selected — վերականգնում է նշվածները՝ հաստատումից հետո։ Նախապայմանները (Check prerequisites)
  ստուգվում են ավտոմատ։ Վերականգնվածները ցուցակում նշվում են «Already the same / Restored just now»։ Գրվում է journal։
Undo last restore — հետ է բերում վերջին վերականգնումը (ձեր հետագայում փոխած ֆայլերը չի ջնջում)։
Check prerequisites — ոչ պարտադիր. ստուգում է՝ Verify-ը անցե՞լ է, պրոֆիլները համապատասխանեցվա՞ծ են, Office-ի և
  runtime-ների համատեղելիությունը, Python-ի պահանջվող տարբերակները։
Options. Drive mapping — օր.՝ D:=E:, եթե սկավառակի տառը փոխվել է։
  Allow overwrite (previous file is saved) — լռելյայն անջատված է. միացնելու դեպքում (և Dry run-ից հետո) արդեն
  գոյություն ունեցող տարբեր ֆայլերը նույնպես կնշվեն որպես Replace. հին ֆայլը պահվում է Undo-ի համար։
Files ցուցակի Action սյունակը. New file — նոր ֆայլ, Replace — փոխարինում, Already the same — արդեն նույնն է,
  Exists (different) — կա տարբեր ֆայլ (աջ սեղմումով կարող եք փոխարինել), No target profile — Step 1-ը լրացված չէ,
  Not possible — համակարգային/ծրագրի պանակ կամ գոյություն չունեցող սկավառակ (տես Reason)։
Ներդիրներ.
  Prerequisites — Severity, Area, Message, Action։
  Files (dry run) — Restore (վանդակ), Action, Target, Category, Reason։ Select all, Clear։
  Registry (review) — Apply (լռելյայն անջատված), Key (HKCU), Value, Type, Current (old), From backup (new),
    Blocked, Warning։ Կիրառվում է միայն ընթացիկ մուտք գործած օգտատիրոջ համար, հին արժեքը պահվում է։
  Python environments — Environment, Python, Arch, Capture, Packages։ Recreate selected environment —
    ցույց է տալիս ճշգրիտ հրամանները, հարցնում է հաստատում, ստեղծում է venv և տեղադրում փաթեթները
    պաշտոնական PyPI-ից։ Եթե փաթեթների ցուցակը Partial/Failed է, արդյունքը լիարժեք չի լինի։
Functional test checklist (file restore is not the same as a working program) — ծրագրերի աշխատանքի ստուգաթերթ.
  Save functional test results — պահում է արդյունքը։ Միայն ֆայլերի վերականգնումը չի նշանակում, որ ծրագիրը աշխատում է։
